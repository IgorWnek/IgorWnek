# Igor Wnęk

**Agentic Product Engineer · AI-native tools and workflows for engineers who ship products**

*I don't build AI agents as a product — I orchestrate coding agents to build products. I teach other engineers to do the same.*

- Based in Poland 🇵🇱
- Senior Agentic Product Engineer at The Software House — on the AI-Native Product Engineering team
- Harness engineering is where I go deep: Claude Code, GitHub Copilot, Codex — instructions, sub-agents, skills, hooks, model routing, token economics
- Ten years of backend engineering and architecture underneath: Node.js, TypeScript, Go, relational databases
- Creator of [IKcode](https://www.youtube.com/@IKcodeIgorWnek) — my company and YouTube channel
- Reach me: <igor.wnek@ikcode.dev>

## What's in my repositories

Customizations for AI coding harnesses — the instructions, agents, skills, and hooks that make coding agents reliable.

- [copilot-collections](https://github.com/TheSoftwareHouse/copilot-collections) — The Software House's open-source Copilot customizations, used across TSH engineering teams. I'm on the core team building it.
- [copilot-kit](https://github.com/ikcode-dev/copilot-kit) — my own portable set of VS Code Copilot customizations.

Everything tied to the IKcode channel lives under [@ikcode-dev](https://github.com/ikcode-dev).

## What's on my YouTube

Hands-on harness engineering: configuring and customizing coding agents, instruction and skill files, sub-agents and hooks, MCP against plain CLI, and comparing models inside a real harness. Screen-share and repo demos — things you can apply the same afternoon.

If a video shows a config, the repo is linked under it.
